# 🎶 Xylophone Android

A simple Android application that simulates a xylophone, allowing users to play musical notes by tapping colorful keys on the screen.

Built as an educational Android project to explore user interactions, audio playback, and Android application development fundamentals.

- 🎵 Play xylophone notes with a simple touch
- 🌈 Colorful and intuitive user interface
- ⚡ Instant audio playback

## 🚀 Getting Started

### Prerequisites

Before running the project, make sure you have:

- Android Studio installed
- Android SDK configured
- Java Development Kit (JDK)

### Clone the Repository

```bash
git clone https://github.com/ContardiC/Xylophone-Android.git
```

### Open the Project

1. Launch Android Studio
2. Select **Open**
3. Choose the cloned project folder
4. Allow Gradle to sync dependencies

### Run the App

1. Connect an Android device or start an emulator
2. Press **Run ▶**
3. Enjoy playing the xylophone!
